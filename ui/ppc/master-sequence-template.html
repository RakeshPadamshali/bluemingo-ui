Sequence Templates

Per mill (and optionally equipment or product family): the ordering rules that pre-arrange the proposed blocks of a rolling schedule — by size, grade, grade family, PSN, input section, slot score or delivery date, ascending, descending or in an explicit list. Mills keep the final authority on the sequence.
Prototype on sample data — every control works; a reload resets. Try: click a template · change a rule's key or direction, move or delete a rule, Add rule — the preview re-orders · make BRM-LARGE-FIRST the default · Deactivate (a default is refused) · resolve which template a schedule uses · Add template · Upload.

Templates one default per mill · click to edit its rules

Which template does a schedule use? the equipment or family template when one exists, else the mill default
