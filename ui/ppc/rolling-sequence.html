Rolling Sequence

One screen for every rolling mill — BRM sequences sizes, BLM sequences RCS sections from the input bloom. Pivot from the finalised campaign, blocks pre-arranged by the mill's sequence template and proposed by Mills, PPC accept / counter, change alerts, frozen after release with changes through a revision, grade-integrity gaps, retrieval lead time, length mapping with bypass, MoQ push, the rolling-plan calculator and setup sheets. Release uploads the rolling program and saves the running order through the existing services of the production-confirmation application.
Prototype on sample data — every control works; a reload resets.
