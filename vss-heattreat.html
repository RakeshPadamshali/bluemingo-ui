Annealing types — plan tonnage per cycle
Same basis as the Dashboard flow strip and the Master Gantt: every RXA / PGS / PXS / PGA order line is charged in ≤ 18 MT boxes, and a box is filled from several orders of the same anneal type whose bar is ready within two days, so the furnace is not fired for a part load (an order over 18 MT still takes more than one box). Charges go to the furnace that can start them soonest, in the order their bar is ready, and the plan lights only as many furnaces as the annealing book needs (total cycle hours ÷ the span the boxes arrive in) so the lit ones run back to back and the rest stay cold. Cycle = anneal time + 12 h cooling / changeover.
