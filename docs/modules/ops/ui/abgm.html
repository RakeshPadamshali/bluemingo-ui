ABGM — grinding operation

The PPC grinding schedule received per machine and day priority; barcode identifies the billet with the section-limit check (no bypass); grinding confirmation on the built card produces the ground code by the form-conversion rule and updates the location (the code-conversion posting: SAP deferred — PPC outbox); three machines, day priority enforced.
