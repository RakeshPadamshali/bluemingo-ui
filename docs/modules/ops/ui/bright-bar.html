Bright Bar — operations, code conversion, packing

Peeling, reeling, centreless grinding (CG1–3), MPI, cutting and packing on the built card with Quality clearances; product-code conversion per BOM level as conversion events (SAP: deferred — PPC outbox); packs with lines per batch and labels; the pending-material monitor per operation.
Prototype on sample data — every control works; a reload resets. Try: click a monitor row to open its work list · Peeling: Start a queued lot → Confirm (conversion L1 → L2) → act as Quality inspector → Clear (or Hold) · Centreless grinding: Confirm a lot in process (L2 → L3) · MPI: Clear · Packing: Pack → New pack (try the scale offline: manual weight) → Close & print label → Final clearance (Quality) → Dispatch · Operation assignment (RO 42 has no weekly line).
